# 쇼핑몰 고객 문의 분류기

쇼핑몰에 들어오는 고객 문의 · 불만 · CS 요청을 읽고 **칸 · 긴급도 · 감정**을 붙이는 분류기입니다.
CS 팀이 문의를 받아 담당 부서로 넘길 때 씁니다.

## 최종 목표와 단계

| 단계 | 할 일 | 상태 |
|---|---|---|
| 1단계 | 문의를 분류하는 분류기 만들기 | 진행 중 (데이터 준비) |
| 2단계 | 분류 결과에 따라 대응하기 (답변 초안, 부서 배정 등) | 예정 |

1단계는 다음 순서로 진행합니다.

1. 합성 데이터 만들기 — 실제 고객 문장은 AI에 보내지 않으므로, 비슷하게 지어낸 문장을 씁니다 ✅
2. 정답 붙이기 — 점수를 잴 35문장에 **사람이** 정답을 붙입니다 ⬅ 지금 여기
3. 견주기 — 사람의 정답과 AI가 생각한 정답을 견주고, 갈린 문장을 보고 기준을 다듬습니다
4. 분류기 만들기 — 문장을 넣으면 칸 · 긴급도 · 감정이 나오게 합니다
5. 점수 재기 — 사람이 붙인 정답으로 분류기가 얼마나 맞히는지 잽니다

## 무엇으로 나누나

자세한 뜻과 규칙은 [데이터명세.md](데이터명세.md)에 있습니다.

| 항목 | 값 |
|---|---|
| 칸 | 배송 · 교환반품 · 결제 · 상품문의 · 기타 (두 칸에 걸치면 앞 칸) |
| 긴급도 | 높음 · 보통 · 낮음 |
| 감정 | 긍정 · 중립 · 부정 |

- 불만은 따로 칸을 두지 않습니다. 불만은 어느 칸에서나 생기기 때문입니다. 대신 긴급도와 감정에 드러납니다.
- 긴급도와 감정은 따로 봅니다. "단골이에요ㅎㅎ 그런데 결제가 두 번 됐어요"는 감정은 긍정이고 긴급도는 높음입니다.

## 폴더 구성

```
my-classifier/
├── README.md              이 파일
├── 데이터명세.md           칸 · 긴급도 · 감정의 뜻, 데이터 구성
└── data/
    ├── practice.json      연습용 70문장 (정답은 AI가 붙임)
    ├── 정답_붙이기.md       사람이 정답을 붙일 35문장
    └── _만든의도.json       35문장에 대해 AI가 생각한 정답 (정답을 다 붙이기 전에는 열지 않기)
```

### practice.json 항목 예

```json
{
  "id": "p01",
  "text": "문의 문장",
  "칸": "배송",
  "긴급도": "보통",
  "감정": "중립",
  "label_by": "AI"
}
```

## 데이터에 대해 알아 둘 것

- **모두 지어낸 문장입니다.** 이름은 가짜이고, 전화번호는 `010-0000-xxxx` 형식입니다. 실제 회사 · 브랜드 · 제품 이름은 없습니다.
- 반말 · 오타 · 이모티콘 · 두 칸에 걸치는 문장을 일부러 섞었습니다.
- 칸은 고르게 나뉘어 있습니다. 감정은 고르지 않습니다(중립 > 부정 > 긍정). 정답 붙이기 35문장 중 긍정은 5개뿐이라, 긍정 점수는 넉넉히 감안해서 봅니다.
- practice.json의 정답은 AI의 판단 하나입니다. 사람이 보면 다르게 붙일 문장이 있을 수 있습니다.
- **점수는 사람이 붙인 정답으로 잽니다.** 문제를 낸 쪽이 답안지까지 쓰면, 틀린 답안이 있어도 아무도 알아채지 못하기 때문입니다.
